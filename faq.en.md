# FAQ

## Account

### My password keeps failing

Use the eye icon to check your input and remove extra spaces. If it still fails, reset it with an email code or your saved recovery code.

### I'm not receiving the verification code

Check your spam/promotions folder. Each address can receive at most 3 codes per minute — wait a moment and retry, and double-check the address. Still nothing? Contact support so we can check delivery logs.

### I forgot my password

Open Forgot password and use either an email code or your email plus a previously saved recovery code. After recovery, save the new code because the old one is invalidated.

## Payments & credits

### I paid but the credits haven't arrived

While the payment page stays open, credits usually arrive within 2–5 seconds. If you left the page, check your recharge history on the top-up page. After 30 minutes, contact support with the order number (merchant order no. in your WeChat bill), payment time and a screenshot; we will make it up once verified.

### Can I get a refund?

Credits are virtual goods delivered instantly; per the Top-up Service Agreement unconditional refunds are not supported. For anomalies such as duplicate charges or missing credits, contact support within 30 days — verified cases are refunded via the original channel or made up in credits.

### The QR code expired after 3 minutes

When the countdown ends the order closes automatically; just place a new order for a fresh code. Unfinished payments are not charged. In the rare case money was taken while the page showed expired, it is credited as a successful top-up — send us the order number.

### How are credits charged?

Billing follows actual usage; see the in-app "Credits & payments" page for the current rates. Longer content consumes more; cache hits are charged at a lower rate, so you already get the discount automatically.

### Do failed generations still cost credits?

Only the usage actually consumed is charged. Failures that never started are fully and automatically refunded — no request needed.

## Creation & materials

### Where do I start after logging in?

The page after login is the project workspace. Create an Original Script, Source to Storyboard, or Script Diagnosis project. Series is a setting inside Original, while Source to Storyboard accepts either novel source text or an existing script.

### How do I manage lots of projects?

Pin frequent projects to the top; the rest are ordered by recently opened. Open All Projects to search by name or to open, import, export, or duplicate a project.

### What is the Characters & Props panel for?

The Characters & Props tab in the workspace keeps a per-project library of characters and props: create entries manually, or import them in one click after generating a script. Once visual descriptions are filled in, scene sketches automatically carry them so the same character stays consistent across shots. Each entry can also get a reference image. Data and images stay on your device and are included in project backups.

### Which file formats can I upload?

txt / md / epub / docx, up to 10MB each. epub/docx are parsed locally in your browser; the file content is not uploaded.

### My novel is too long to process at once

Run "Compress" on the source text in the materials library first, then reference the compressed version while creating — it costs fewer credits and yields steadier results. The original text is always kept.

### I'm not happy with the generated script

Ask for changes directly in the chat (outline, shots, lines — anything), or regenerate with a different tone/director style. AI output isn't guaranteed to match expectations; incremental edits usually beat full regenerations.

### What if a generation stalls, disconnects, or needs to stop?

Check the task card in the project. You can stop a running task; actual usage already incurred is still settled, and it is not marked complete. Once a task card has appeared, progress is restored after a refresh, disconnection, or reopening the project. If the connection drops before the card appears, do not click repeatedly; note the time and contact support. Continue a failed task only when the UI offers Continue unfinished steps or Retry.

### Can I view or return to an older version?

Outline and script history can be selected in the results panel. Old versions are read-only, and Continue from this version creates a new one. Linked artifacts such as novel digests, series outputs, storyboards, and diagnosis reports also keep history, but their history cannot yet be selected in the UI.

### Will my data survive a device or browser switch?

Creations, materials, and memories stay in your browser by default and do not sync automatically. Export a complete JSON from Data backup and recovery in Profile, then import it on the new device. An active standard subscription can explicitly enable encrypted cloud backup (off by default, one latest snapshot); boost cards do not include it.
